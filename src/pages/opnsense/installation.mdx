# Install OPNsense

## Download the ISO

1. Go to [https://opnsense.org/download/](https://opnsense.org/download/)
2. Select **amd64** and image type **dvd**
3. Extract the `.iso.bz2` file
4. Upload the `.iso` to Proxmox: **Datacenter → Node → local → ISO Images → Upload**

## Create the VM

Go to **Datacenter → Node → Create VM** and use these parameters:

| Setting | Value |
|---------|-------|
| **Name** | `GW` |
| **VM ID** | `100` |
| **OS** | Type: **Other** |
| **System** | Machine: `q35`, BIOS: `OVMF (UEFI)`, **uncheck** "Pre-Enroll keys" (Secure Boot off) |
| **Disk** | SCSI, 32 GB |
| **CPU** | 2 cores, Type: `host` (for AES-NI) |
| **Memory** | 8 GB |
| **Network 1** | Bridge: `vmbr0`, Model: `VirtIO`, Multiqueue: `2` |
| **Start at boot** | ✅ Enable this in Options |

After creation, add a second network device:

- **Hardware → Add → Network Device**
- Bridge: `vmbr1`, Model: `VirtIO`, Multiqueue: `2`

<Note>
  In **Options → Boot Order**, make sure the CD/DVD drive is first for the initial install.
</Note>

## Install the OS

1. Start the VM and open the console
2. At boot, press any key when you see `Press any key to start the manual interface assignment`
3. Assign interfaces:
   - **WAN:** `vtnet0` (connected to `vmbr0` / physical network)
   - **LAN:** `vtnet1` (connected to `vmbr1` / internal VMs)
   - Optional: press Enter to skip additional interfaces
4. Confirm with `y`
5. Log in as `installer` / `opnsense`
6. Install with **Auto (UFS)** partitioning (avoid ZFS inside a VM on a ZFS host)
7. Set a root password when prompted
8. Reboot and remove the ISO from the VM hardware

## Initial console configuration

After reboot, log in as `root` with your password at the console:

1. Press `1` to assign interfaces (verify WAN and LAN are correct)
2. Press `2` to set interface IP addresses:
   - **LAN:** `10.11.0.1/16` (must differ from the physical network subnet)
   - Enable DHCP server on LAN: `Y`
   - DHCP range: `10.11.10.0` to `10.11.20.0` (this will be refined per VLAN later)
   - Leave IPv6 blank for now
3. **WAN** should pick up an IP via DHCP from your physical router automatically

## Access the web GUI

From a VM connected to `vmbr1`, or from your Proxmox host if it has access, browse to: `https://10.11.0.1`

Login: `root` / your password

## Run the setup wizard

1. **General Setup:** Set the hostname and DNS (you can use `8.8.8.8` or your physical router)
2. **WAN Configuration:** Should already be DHCP. If your physical router gives RFC1918 IPs (like `192.168.1.x`), **uncheck** "Block RFC1918 networks" on the WAN interface, or you will block your own upstream
3. **LAN Configuration:** Already set to `10.11.0.0/16`
4. Set a strong admin password

## Route other VMs through OPNsense

For each VM or LXC that should use OPNsense as its router:

1. Go to **VM Hardware → Network Device**
2. Set **Bridge** to `vmbr1`
3. Set **Model** to `VirtIO`

These VMs will receive DHCP IPs in `10.11.10.x` from OPNsense and route through it.
