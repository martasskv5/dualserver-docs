# Install Authentik

Authentik runs as a Docker container inside an LXC. The installation follows the [official Docker Compose guide](https://docs.goauthentik.io/install-config/install/docker-compose).

## Create the LXC container

Create a new LXC with Docker pre-installed using the [Docker community script](https://community-scripts.org/scripts/docker):

```bash
var_cpu="2" var_ram="4096" var_disk="10" bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVE/main/ct/docker.sh)"
```

<Note>
  In the future this will be replaced by a custom silent-install script with all parameters preset, enabling a fully automated Authentik deployment.
</Note>

## Set up the Authentik container
Connect to the LXC and create a directory for Authentik:
```bash
mkdir ~/compose && cd ~/compose
wget https://docs.goauthentik.io/docker-compose.yml
```

Create a .env file with the required secrets:
```bash
echo "PG_PASS=$(openssl rand -base64 36 | tr -d '\n')" >> .env
echo "AUTHENTIK_SECRET_KEY=$(openssl rand -base64 60 | tr -d '\n')" >> .env
echo "COMPOSE_PORT_HTTP=80" >> .env
echo "COMPOSE_PORT_HTTPS=443" >> .env
```

Pull and start the containers:
```bash
docker compose pull
docker compose up -d
```

## Set a static IP address
In OPNsense, create a static DHCP lease for the Authentik container. This ensures the container always receives the same IP address. Assign it a DNS hostname as well, for example auth.pve99.local.

## First login
Browse to the container IP or hostname. The default credentials are:

- Username: akadmin
- Password: Printed in the container logs on first start. Retrieve it with:

```bash
docker logs authentik-server 2>&1 | grep "Initial setup"
```

Change the password immediately after logging in.
