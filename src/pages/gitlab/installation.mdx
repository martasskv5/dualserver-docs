# Install GitLab

## Create the LXC container

Create an LXC container with the following parameters:

| Parameter | Value |
|-----------|-------|
| CPU | 2 cores |
| RAM | 4096 MB |
| Disk | 40 GB |
| Network | DHCP on `vmbr1` |
| Features | `nesting=1`, `keyctl=1` |
| Hostname | `gitlab` |

See [Create LXC](/proxmox/create-lxc) for the full procedure.

<Note>
  The `nesting=1` and `keyctl=1` features are required for GitLab to work properly inside an LXC container.
</Note>

## Install GitLab CE

Follow the [official Debian installation guide](https://docs.gitlab.com/install/package/debian/?tab=Community+Edition).

If you encounter locale errors during installation, run:

```bash
# 1. Ensure the locale is uncommented in locale.gen and actually generated
sed -i 's/^# *en_US.UTF-8 UTF-8/en_US.UTF-8 UTF-8/' /etc/locale.gen
locale-gen en_US.UTF-8

# 2. Verify it is really there
locale -a | grep en_US

# 3. Set system-wide locale properly
update-locale LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8

# 4. Export for current session
export LANG=en_US.UTF-8
export LC_ALL=en_US.UTF-8

# 5. Clear any stale PostgreSQL data
rm -rf /var/opt/gitlab/postgresql/data/*

# 6. Reconfigure GitLab
gitlab-ctl reconfigure
```
### Fix host shared memory issue
To make GitLab work properly in LXC, apply missing kernel parameters.
Open `/etc/sysctl.conf` and add:

```
kernel.sem=250 32000 32 262
kernel.shmall=4194304
kernel.shmmax=17179869184
net.core.somaxconn=1024
```

Apply the changes:

```bash
sysctl -p
```
Restart the LXC container to apply everything.
