# Proxmox Overview

Proxmox VE is the hypervisor that runs every virtual machine and LXC container in the DualServer environment. It provides the compute, storage, and network bridges that all other services depend on.

## What Proxmox handles

| Responsibility | Details |
|----------------|---------|
| **Virtual machines** | OPNsense runs as a VM with dedicated network devices |
| **LXC containers** | Authentik, GitLab, Postfix, and student servers run in unprivileged LXCs |
| **Storage** | Local ZFS pools hold ISO images, templates, and container rootfs |
| **Network bridges** | `vmbr0` connects to the physical network; `vmbr1` is the internal LAN |
| **Templates** | A single Debian 13 LXC template is prepared with LDAP and SSH pre-configured |

## Architecture

The physical server runs Proxmox. OPNsense is the first VM created and owns the routing between the physical network and the internal virtual network. Every other service lives behind OPNsense on `vmbr1` with a VLAN tag that places it in the correct segment.
