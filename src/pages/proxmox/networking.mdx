# Networking

Whole networking is handled by [OPNsense](/opnsense/overview), but Proxmox has to provide underlying network interfaces to OPNsense. This is done by creating a Linux bridge in Proxmox and connecting it to the physical network interface. Then, the OPNsense VM will be connected to this bridge. This will be a WAN interface for OPNsense. For LAN we create additional bridge with VLANs enabled. All VMs and LXC containers will be connected to this LAN bridge. OPNsense will handle all routing and firewalling between WAN and LAN.

| Bridge  | Purpose | Connected To                            |
| ------- | ------- | --------------------------------------- |
| `vmbr0` | WAN     | Physical network - should already exist |
| `vmbr1` | LAN     | Internal — only VMs connect here        |

## Create LAN bridge

Go to **Proxmox Web UI → Node → System → Network → Create → Linux Bridge**
<p>
    <img src="/docs-static/img/proxmox/networking/create-lan-bridge.png" alt="Create Linux Bridge" className="imagewrapper"/>
</p>

## Adding a new device to the internal network

When creating a new VM or LXC container, select the LAN bridge `vmbr1` as the network device. This will connect the VM or LXC to the internal network. OPNsense will handle all routing and firewalling between WAN and LAN.

<Warning>
    Dont forget to add a VLAN tag to the network device. This is required for OPNsense to handle VLANs properly. Otherwise, the VM or LXC will not be able to communicate with OPNsense and other devices on the internal network.
</Warning>
