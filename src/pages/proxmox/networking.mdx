# Networking

All routing and firewalling is handled by [OPNsense](/opnsense/overview), but Proxmox must provide the underlying network interfaces. This is done by creating a Linux bridge connected to the physical network interface for WAN, and a second internal bridge for LAN traffic.

| Bridge | Purpose | Connected To |
|--------|---------|--------------|
| `vmbr0` | WAN | Physical network — created automatically during Proxmox install |
| `vmbr1` | LAN | Internal — only VMs and LXCs connect here |

## Create the LAN bridge

1. Go to **Proxmox Web UI → Node → System → Network → Create → Linux Bridge**
2. Set **Name** to `vmbr1`
3. Leave **Bridge ports** empty (no physical interface)
4. Enable **VLAN aware** if the option is available
5. Save and apply configuration

## Connect a VM or LXC to the internal network

When creating a new VM or LXC container:

1. Under **Network Device**, set **Bridge** to `vmbr1`
2. Set **Model** to `VirtIO` (VMs) or leave default (LXC)
3. Add the correct **VLAN tag** for the target network segment

OPNsense handles all routing, DHCP, and firewall rules between WAN and LAN.

<Warning>
  Do not forget to add a VLAN tag to the network device. OPNsense uses VLANs to segment the internal network. Without a tag, the device will not receive a DHCP lease and cannot communicate with other services.
</Warning>
