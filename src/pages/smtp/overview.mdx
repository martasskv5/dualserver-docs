# SMTP Overview

Postfix acts as a local SMTP relay for the DualServer environment. It accepts email from GitLab, Authentik, and any other internal service, then forwards it to an external SMTP server — in this case, Microsoft 365.

## Why a local relay?

| Benefit | Explanation |
|---------|-------------|
| **Single configuration point** | Every service points to the same internal host |
| **Credential isolation** | Only Postfix stores the external SMTP password |
| **Testing** | Development environments can send real email without exposing credentials in every app |
| **Reliability** | If the external service is briefly unavailable, Postfix queues mail automatically |

## Architecture
```
[GitLab] ──┐
[Authentik]─┼──► [Postfix on VLAN 10] ──► [Microsoft 365] ──► Internet
[Other apps]─┘
```
