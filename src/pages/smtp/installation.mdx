# Install Postfix

## Create the LXC container

Create an LXC container with the following parameters:

| Parameter | Value |
|-----------|-------|
| CPU | 1 core |
| RAM | 512 MB |
| Disk | 20 GB |
| Network | DHCP on `vmbr1`, VLAN `10` |
| Features | `nesting=1`, `keyctl=1` |
| Hostname | `postfix` |

See [Create LXC](/proxmox/create-lxc) for the full procedure.

<Note>
  Place Postfix on VLAN 10 (Management) so every other VLAN can reach it, but students cannot access it directly.
</Note>

## Install Postfix

Inside the container:

```bash
apt update && apt install -y postfix libsasl2-modules
```
During installation, select **Internet Site** and set the system mail name to your domain (e.g., pve99.local).
